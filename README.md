## 🚀 Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Set up environment
cp .env.example .env
# Edit .env with your PostgreSQL DATABASE_URL

# 3. Set up the database
npx prisma db push
npx prisma generate
npm run db:seed

# 4. Start development server
npm run dev
```

**Visit** [http://localhost:3000](http://localhost:3000)
